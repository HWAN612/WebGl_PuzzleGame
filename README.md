# ⭐ CatchStar - WebGL Build

같은 색 별을 이어서 터뜨리는 모바일 퍼즐 게임, **CatchStar**의 WebGL 빌드를 배포하기 위한 레포지토리입니다.
Web에서도 플레이해볼 수 있도록 GitHub Actions를 통해 자동으로 빌드 및 배포됩니다.

기획부터 출시까지 **2인 개발**로 진행했으며, Google Play에 정식 출시를 완료했습니다.
